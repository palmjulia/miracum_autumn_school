# fhircrackr: Einführungsworkshop Miracum Autumn School 2026

Materialien zum Workshop "Einführung in den fhircrackr", einem R-Paket zum Herunterladen und Verflachen von HL7 FHIR Ressourcen.

## Inhalt

| Dtei/Ordner | Beschreibung |
|---|---|
| slides | Folien, Quellcode/html |
| intro.R | Der gesamte Code aus den Folien zum Mitmachen |
| aufgabe | Abschlussaufgabe, PDF/Lösungen|

## Voraussetzungen

-   [R](https://cran.r-project.org/) und [RStudio](https://posit.co/download/rstudio-desktop/) installiert
-   Internetzugang


## Verwendung

1.  Repo herunterladen (grüner Button **Code** → **Download ZIP**) oder klonen
2.  `intro.R` in RStudio öffnen
3.  Code zeilenweise ausführen (`Strg + Enter`)
